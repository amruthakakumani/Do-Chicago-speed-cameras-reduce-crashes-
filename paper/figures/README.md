# Publication figures

All figures are generated by `scripts/make_publication_figures.py` from saved
artifacts and cleaned data. PNG is 300 dpi; SVG is vector.

| Figure | Source | Caption |
|---|---|---|
| `fig1_study_map` | `data/processed/cameras.parquet`, `results/sites.parquet`, crash sample | Camera and comparison locations with crash density |
| `fig2_catchment_overlap` | `data/processed/cameras.parquet` | Overlapping 250 m catchments; 107 pairs <500 m |
| `fig3_causal_estimates` | `results/estimates.json`, `results/tables/sensitivity.csv`, `results/bottom_up/coverage_causal/estimates.json` | Original, revised and coverage-consistent causal estimates |
| `fig4_event_study` | `results/tables/event_study.csv`, `results/estimates.json` | Dynamic event-study effects |
| `fig5_pretrends` | `results/analysis_panel.parquet` | Pre-treatment trends |
| `fig6_forecast` | `results/ml/v1/predictions.parquet` | Observed versus LightGBM forecasts |
| `fig7_calibration_highrisk` | `results/ml/v1/metrics.json`, V1 predictions | Calibration and error by crash level |
| `fig8_interval_coverage` | `results/ml_v2/metrics.json` | Conformal interval coverage by risk decile |
| `fig9_reporting_coverage` | `results/bottom_up/coverage/monthly_coverage.csv` | September 2017 citywide reporting break |
| `fig10_model_comparison` | `results/bottom_up/coverage_model/common_metrics.csv` | V1/V2/coverage-consistent models on common test rows |
